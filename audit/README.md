# 全故事分支核對清單

`build-inventory.cjs` 從目前 world.js 與 story.js 產生 `story-inventory.json`，包含所有故事條目、直接行動引用、原文、候選選擇語句、解析出的選項及核對紀錄。沒有直接行動引用的條目仍可能被其他故事或書頁引用，不能據此刪除。

`review-evidence.json` 只記錄已實際查閱原書、檢查程式並驗證的範圍。既有測試尚未逐一登錄，不應把未登錄等同未做過；也不能把測試存在當作已核對全部規則。`textChanged` 會提示核對後文字已變更，程式邏輯改變仍需另外評估。

關鍵字與通用分支解析只用來排序，專用骰子、謎題或條件處理可能沒有通用分支。每筆仍需核對原文的選擇、前置支付、共通效果、獨立結果、後續行動與存檔。完成判斷不能只看掃描數量。
